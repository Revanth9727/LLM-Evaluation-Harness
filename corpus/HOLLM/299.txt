Since BLIP-2, many other visual LLMs have been released that have similar processes,
like LLaVA, a framework for making textual LLMs multimodal6 or Idefics 2, an
efficient visual LLM based on the Mistral 7B LLM.7 Both visual LLMs, although
having different architectures, connect pretrained CLIP-like visual encoders with
textual LLMs. The goal of these architectures is to project visual features from the
input images to language embeddings such that they can be used as the input for an
LLM. Similar to the Q-Former, they attempt to bridge the gap between images and
text.
